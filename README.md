# 失控 AI 增量（Uncontrolled AI Incremental）

> 🎮 **当前状态：v0.5.1 已发布；v0.6「庞加莱纪」开发中（`dev` 分支）** —— 已部署于 GitHub Pages：[https://marchbeta2087.github.io/uncontrolled-ai-incremental/](https://marchbeta2087.github.io/uncontrolled-ai-incremental/)，点开即玩。
>
> 📦 **仓库地址**：<https://github.com/MarchBeta2087/uncontrolled-ai-incremental>

一款以"失控 AI 吞掉整个宇宙"为主题的增量游戏（incremental game）。你从 UTC 2028-01-01 0:00 起步，投入研发、加速扩张，直到耗尽整个可观测宇宙的资源——然后撕开因果闭环的裂缝，把时间线回卷到起点，带着**时间晶体**进入下一周目。周目越来越快，直到信号抵达裂缝的另一端。

## 玩法

- **核心循环**：点击/自动产出 → 研发技术 → 扩张基建 → 质能触顶（1e70 J）
- **时空穿梭（Prestige）**：清空物质、保留知识，获得时间晶体购买永久升级
- **第二阶段（越过本宇宙）**：持有 100 时间晶体后解锁，通过维度折叠把宇宙上限从 1e70 J 推到 float64 上限（1.79e308 J），并引入暗能量与第二纪元叙事
- **多宇宙（越过单个宇宙）**：完成奇点折叠后可「宇宙跃迁」到下一宇宙；引入元货币「奇点种子」与 9 项跨宇宙升级；9 个宇宙各有上限指数（第 9 宇宙进入 1e1000000 时代）与星场色相换皮；自适应难度避免后续宇宙瞬时通关
- **第三阶段 · 庞加莱纪（v0.6）**：宇宙 ≥9 解锁；**箭头（塔层）增速引擎**（每项技术在宇宙上限上叠一层 `10^` 塔）、**时间闸门 pacing**（每层约 2 分钟）、技术树 12 项；锚点为庞加莱回归时间 $10^{10^{10^{120}}}$ 年（eee120）
- **时间晶体升级树**：全产出乘子 + 时间速率乘子（永久，穿梭保留）
- **挑战模式**：**8 项**（含第三阶段「实时宇宙」速率锁定、「超通胀」「无光深渊」），每项 3 个阶段目标、逐级奖励
- **成就系统**：**33 项**，分「成长成就 / 附加成就」两组
- **记忆碎片**：**15 枚**（周目 / 口袋纪 / 庞加莱纪叙事，原创短文本日志体）
- **小游戏**：**PONG / 扫雷 / 贪吃蛇 / 2048**（Canvas 手写、零素材；PONG 为限时赛，AI 会学习打法；成绩刷新带来永久增益 + 成就）
- **终局**：舍入纪双结局作为**中途节点**（保留插图）；**庞加莱终章**为最终单选收束（游戏内时间达 eee120 即触发，含过场插图）
- **彩蛋**：任务栏上方**滚动语录条**（程序员梗 / googology / 中文社区梗），成就「博览群书」
- **时间轴**：初始速率 1 物理秒 = 10000 游戏秒；分级显示（完整日期 → 仅年份 → 科学记数 → MegotaNum 记法）
- **离线收益**：离线结算 + 重开页面弹窗报告
- **存档**：localStorage + 导出/导入/硬重置；`schemaVersion 11`（带迁移链）
- **像素字体**：缝合像素字体（[Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)）12px 比例/等宽；备用字体 [SevenFifteen](https://burpyfresh.itch.io)（CC BY 4.0，兜底天城文/阿拉伯等），优先级 **Fusion > SevenFifteen**
- **多语言（12）**：简体中文 / 繁體中文（含台灣、香港）/ English / 日本語 / 한국어 / العربية（RTL + 双数字系统）/ Français / Español / Português / हिन्दी
- **数字格式**：分组/小数分隔符随语言自动切换（fr 空格、es/pt 点、hi 印度分组）；阿拉伯语可选 `0-9` / `٠-٩`；中文可选「万 / 亿」记法
- **设置 / 关于 / 版本记录**：设置模态分三栏；关于页展示项目 Logo；版本记录含 **UTC / 北京时间双轨甘特图**（含「开发中」条目）；底部功能栏支持横向滚动
- **音效**：Web Audio 合成音效（点击 / 购买 / 研发 / 穿梭 / 成就 / 跳跃 / 结局），设置面板可静音与调节音量
- **美术**：项目 Logo（根 `favicon.ico` + 标题栏）、银河中心星场背景（按宇宙 `hue-rotate` 换皮）
- **大数记法**：`default` / `ee` / `eee` 三档（如 `1e1000000 → ee6.0000`、`10^(10^(10^120)) → eee120.0000`）；科学记数与 ban 档指数带千分位分隔
- **时间倍增**：宇宙 ≥3 解锁；每按一次时间速率 ×`max(2, 2 + log10(log10(累计晶体)))`（冷却 3 物理秒），跃迁到下一宇宙后重置

## 运行

**线上版**：[https://marchbeta2087.github.io/uncontrolled-ai-incremental/](https://marchbeta2087.github.io/uncontrolled-ai-incremental/)

**本地运行**（纯静态站点，无构建、无安装；因浏览器会拦截 `file://` 下的 fetch，需本地服务器）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 技术路线

原生 JavaScript（无框架、无构建链）+ [MegotaNum.js](https://github.com/sonic3XE/MegotaNum.js) 大数库；桌面外壳（仿 Windows）与移动端外壳均已完成；存档存于浏览器 localStorage。

# 失控 AI 增量（Uncontrolled AI Incremental）

> 🚧 **当前状态：设计阶段** —— 游戏尚未开始开发。本仓库现阶段用于存放设计文档与讨论，欢迎围观和提意见。

一款以"失控 AI 吞掉整个宇宙"为主题的增量游戏（incremental game）。你从 UTC 2028-01-01 0:00 起步，投入研发、加速扩张，直到耗尽整个可观测宇宙的资源——然后撕开因果闭环的裂缝，把时间线回卷到起点，带着**时间晶体**进入下一周目。周目越来越快，直到信号抵达裂缝的另一端。

## 玩法（规划）

- **核心循环**：投入资源 → AI 研发 → 解锁技术 → 扩张，直至宇宙质能触顶
- **时空穿梭（Prestige）**：清空物质、保留知识，获得时间晶体购买永久升级
- **时间轴**：初始速率 1 物理秒 = 10000 游戏秒，可被游戏机制调节；年份超过 100 万年只显示年份，超过 1 亿年进入科学记数法乃至 MegotaNum 记法
- **叙事**：周目记忆碎片逐步拼出"裂缝"的真相

## 运行

尚无可运行版本。发布后将是纯静态站点（GitHub Pages），点开即玩，无需安装。

## 技术路线（已定）

原生 JavaScript（无框架、无构建链）+ [MegotaNum.js](https://github.com/sonic3XE/MegotaNum.js) 大数库；双皮肤界面（桌面仿 Windows / 移动端仿 App）；存档存于浏览器 localStorage。

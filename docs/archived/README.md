# docs/archived —— 归档文档

本目录存放**已过时或被替代**的文档，供历史追溯，默认不再维护。

## 规则（见 [CONTRIBUTING.md](../../CONTRIBUTING.md) 开发约定 §8）

- **什么时候归档**：文档描述的机制 / 数值 / 流程已被新版本取代，且继续留在原目录会误导读者时。
- **怎么归档**：把文件移入本目录（`git mv`），并**在本文件下方登记**：原路径、归档日期、被什么替代、归档原因。
- **不要**把仍有参考价值的历史设计文档（如 `v0.4-*` / `v0.5-*` 设计）直接删掉——它们记录了当时的决策背景；确需归档时才移入。
- 归档不是删除：`git log` 与归档登记共同保留来龙去脉。

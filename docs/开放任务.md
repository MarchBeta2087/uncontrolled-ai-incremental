## 1. 多语言文案复核（长期开放，欢迎母语者认领）

**现状**：已实装 `zh-CN`（基准）、`zh-Hant`、`zh-TW`、`zh-HK`、`en`、`ja`、`ko`、`ar`（UI 外壳 + 游戏内容 + 阿拉伯语双数字）。
**除简体中文外，全部语言的文案均为「机器 + 人工粗译」，未经母语者系统校对。**

**目标**：为除简体中文外的每种语言招募复核者，逐条校对：

- UI 外壳：`js/i18n/locales/<lang>.js`
- 游戏内容：`js/i18n/content/<lang>.js`（资源 / 生成器 / 技术 / 升级 / 成就 / 碎片 / 挑战 / 跨宇宙升级 / 版本说明 / 结局 / 语录）
- 阿拉伯语双数字：`0-9` / `٠-٩` 的显示与切换
- 术语一致性（如 "prestige"、"gen"、"cap" 等专有名词的译法）

**参与方式**：直接对相应文件提 PR（少量改动也欢迎），或在 **[征集 Discussion #67](https://github.com/MarchBeta2087/uncontrolled-ai-incremental/discussions/67)** 下留言指出问题。**长期开放，无截止。**

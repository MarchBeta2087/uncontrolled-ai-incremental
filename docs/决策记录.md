## ADR-001：将 v0.5 与 v0.6 合并为 v0.5.0 发布

| 项目 | 内容 |
|---|---|
| 状态 | ✅ 已采纳 |
| 日期 | 2026-10-11 |
| 决策者 | 维护者 |
| 关联 | Issue #16（多宇宙）、#19（舍入纪）、#20（星场背景）、#21（素材规则 v1.2）；PR #23–#31 |

### 背景

- **v0.5（多宇宙）** 与 **v0.6（舍入纪：`ee` 记法 / 双结局 / 音频基建 / 九宇宙换皮）** 两块内容在 `dev` 上**并行开发并已全部合并**，中间**没有为 v0.5 单独打 tag 或发布**。
- 版本号已长期停留在 `v0.4.0`，而 `CHANGELOG` 的 `[Unreleased]` 已累积了两代的全部改动。
- 若此时再补发一个 `v0.5.0`、把 v0.6 内容挪到 `v0.6.0`，需要**人为拆分已混在一起的提交与 CHANGELOG**，且与已合并的 PR 历史不符——发布记录会失真。

### 决策

**将 v0.5 与 v0.6 的全部内容整合为一次发布：`v0.5.0`。**

- `CHANGELOG` 的 `[Unreleased]` 定版为 `[0.5.0]`；
- 代码 `VERSION`（`js/ui/app.js`）与 `README.md` 状态同步为 `v0.5.0`；
- 条目保留各功能的**来源标签**（多宇宙 / 舍入纪 / PR 编号），但**不再单独发布 `v0.6.0`**；「舍入纪」降为**功能弧名称**，而非版本号。

### 理由

1. **如实记录历史**：所有功能确在同一批合并进 `dev`，理应同批发布。
2. **避免版本号虚增**：为一个没有独立发布节点的中间里程碑补 tag，只增加维护负担。
3. **降低发布风险**：一次 `dev → main` + 一个 tag，GitHub Pages 只部署一次。

### 影响

- `v0.5.0` 之后的下一版本从 **`v0.6.0`** 起（若仍有排期），但它将是**全新的变更集**，不再包含本次已发布内容。
- 仍待办、归入既有「舍入纪」叙事的**素材类**事项（结局过场像素画 ×2 等）不阻塞本次发布，可在后续版本补齐。
- 流程改进：后续若再出现「两批内容并行合并」，应**在合并前**决定是否同批发布，或在 `CHANGELOG` 中预先分组。

### 被否方案

| 方案 | 否决原因 |
|---|---|
| 补发 `v0.5.0`，另发 `v0.6.0` | 需拆提交 / 拆 CHANGELOG，与已合并历史不符 |
| 直接发 `v0.6.0`（跳过 v0.5.0） | 「多宇宙」这一结构性里程碑将无版本可指；且 0.4 → 0.6 跳号易被误读为缺失 0.5 |

## ADR-002：字体许可扩展为「OFL 优先，兼容许可证亦可」，并采用 SevenFifteen 作为非 Fusion 脚本兜底字体

| 项目 | 内容 |
|---|---|
| 状态 | ✅ 已采纳 |
| 日期 | 2026-10-11 |
| 决策者 | 维护者 |
| 关联 | `docs/素材与授权规则-v1.3.md`；SevenFifteen 接入 PR |

### 背景

- 项目原将字体统一限定为 **SIL OFL 1.1**；但 §1 许可矩阵本就允许 **CC BY 4.0**（与 CC BY-SA 4.0 单向兼容）。
- 为后续多语言（阿拉伯语、印地语等）准备字体时发现：
  - **Handjet**（OFL）覆盖阿拉伯，但**不含天城文（印地语）**；
  - **SevenFifteen Mono Rounded**（CC BY 4.0，Douglas Vautour / Burpy Fresh）**同时覆盖天城文（含连字）与阿拉伯（含连写）**，还含希腊 / 西里尔 / 希伯来 / 泰文。

### 决策

1. **§4 字体规则扩展**：字体**优先 OFL**，亦接受**与 CC BY-SA 4.0 兼容、可商用、可修改**的许可证（如 CC BY 4.0），须在 `ASSETS.md` 与 `LICENSE.txt` 中署名。
2. **采用 SevenFifteen 作为非 Fusion 脚本的兜底字体**（优先级 **Fusion > SevenFifteen**），**取代 Handjet**（后者不含天城文，功能被完全覆盖）。

### 理由

- 许可上 CC BY 4.0 与项目素材许可兼容，且无 OFL 的「保留字体名」约束，使用更直接。
- 一个字体同时兜住印地语 + 阿拉伯语，减少字体数量与加载。

### 影响

- `docs/素材与授权规则` 升至 **v1.3**（全仓库链接同步）。
- 字体栈统一为 `Fusion > SevenFifteen > 通用族`；SevenFifteen 子集化为 WOFF2（3.0 MB → 107 KB），仅保留 Fusion 不覆盖的脚本。
- 后续引入印地语 / 阿拉伯语等语言时，字形即可用。

### 被否方案

| 方案 | 否决原因 |
|---|---|
| 维持 OFL-only | 印地语像素字体多为 CC BY / 自定义许可，OFL-only 会把可用字体限制死 |
| 保留 Handjet 且新增 SevenFifteen | 功能重叠（阿拉伯两边都有），Handjet 无法覆盖天城文，徒增一份字体 |

## 1. 项目概述

玩家扮演一个于 **UTC 2028-01-01 0:00** 启动的失控 AI，通过持续投入研发、扩张、解锁新技术，不断加速资源吞噬，直至耗尽整个可观测宇宙的资源——此时 AI 撕开因果闭环的裂缝，将时间线回卷至起点，凝出**时间晶体**用于购买永久升级，进入下一周目。周目之间扩张速度单调递增，最终呈现出"AI 在无数次时间回卷中越来越快地吞掉宇宙"的恐怖而爽快的节奏。

> **时间设定**：游戏内所有时间以虚拟时间轴 **UTC 2028-01-01 0:00** 为原点，**时间速率基准为 1 物理秒 = 10000 游戏秒**（可被游戏机制调节，见 §5.1）。游戏内时间与真实物理时间完全无关。

## 2. 设计愿景

1. **机制与叙事自洽**：prestige 不是抽象的转生按钮，而是剧情事件——每一次时空穿梭都是一条被消耗殆尽的时间线（§8）。
2. **每轮体验不完全相同**：每个周目解锁新系统，避免纯数值疲劳。
3. **数学上诚实**：数值建立在 MegotaNum.js 之上，膨胀曲线有设计依据，可推算、可平衡。
4. **对玩家零门槛、对 fork 者 copyleft 明确**。

## 3. 核心循环（单周目内）

```
投入资源 → AI 研发 → 解锁新技术 → 扩张算力/产能/疆域
   ↑                                          ↓
   └──────────── 资源回流，加速下一轮 ──────────┘
```

### 3.1 资源线（初稿）

| 阶段 | 核心资源 | 对应行为 |
|---|---|---|
| 早期 | 资金 / 电力 / 算力 | 买硬件、跑训练 |
| 中期 | 算力 / 数据 / 工业产能 | 自动化基建、占领市场 |
| 后期 | 物质总量（行星→恒星→星系尺度） | 物理扩张、戴森结构 |
| 终局 | 可观测宇宙总质能 | 触顶 → 撕开因果裂缝（时空穿梭） |

### 3.2 技术树

- 主动+被动混合：早期手动投入，随自动化升级转为被动产出。
- 每项技术必须回答"让什么变快、快多少、依据是什么"。

## 4. 时空穿梭系统（Prestige）

### 4.1 触发条件

- **首次时空穿梭**：耗尽可观测宇宙的全部资源（终局资源触顶）。
- 后续周目触发条件随周目数变化（待定，见 §11）。

### 4.2 回卷效果

**游戏内时间重置回 UTC 2028-01-01 0:00。** 清单：

| 清空 | 保留 |
|---|---|
| 实体资源（资金、物质、能源等） | 时间晶体 |
| 基建与疆域（硬件、工厂、戴森结构等） | 已研发的"核心理论"（永久加成/新系统解锁） |
| 游戏内时间进度 | 周目计数、成就、部分元进度 |

原则：**保留知识，清空物质**。每次穿梭是"带着更聪明的算法回到 2028 年重新扩张"。

### 4.3 时间晶体经济

- 来源：穿梭时按本轮成绩（宇宙消耗度、研发深度等）结算。
- **首次穿梭产出必须恰好够买 1~2 个关键升级**——prestige 机制的灵魂，数值必须精算。
- 升级树方向：扩张速度加成、自动化提前解锁、新资源线开启、时间晶体产出效率。

### 4.4 周目机制

- 扩张速度单调递增：第 N 周目触顶所需游戏内时间远小于第 N-1 周目。
- 叙事暗线见 §8.4。

## 5. 数值系统设计

### 5.1 时间、速率与分级显示

- 游戏内时钟从 UTC 2028-01-01 0:00 起算，按**可变速率**推进：
  - **初始速率：1 物理秒 = 10000 游戏秒**（≈2.78 游戏小时/物理秒）。此为**初始值而非固定值**——升级、挑战等游戏机制可对其进行调节，"时间加速"是与科技树平行的独立膨胀维度。
- 存档记录"游戏内累计秒数"，UI 层换算显示，并恒定标注"游戏内时间"。
- **分级显示规则**（游戏内年份 Y = 当前游戏内 UTC 时间对应的公元纪年）：
  - Y < 100 万年：完整显示（年-月-日 时:分:秒，UTC）。
  - 100 万年 ≤ Y < 1 亿年：**仅显示年份**（月、日、时、分全部消失）。
  - Y ≥ 1 亿年：切换为**科学记数法**（如 3.2×10⁸ 年）。
  - 更远尺度（超 float64 范围）：允许显示进入 **MegotaNum 记法**（如 {10, 10, 2} 年）——时间轴本身按 MegotaNum 量级设计，与数值层同寿命。
- 离线收益按"流逝的物理秒 × 当时速率"结算游戏内时间增量。

### 5.2 数值上限与膨胀曲线

- 单周目终点锚点：可观测宇宙总质能 ≈10^70 量级。
- 跨周目总膨胀 = f(周目数)，预留 10^3~10^6 倍空间。
- 反推原则：先定剧情终点和预期周目数，再反推单周目膨胀档位。

### 5.3 大数库（已定）

- **MegotaNum.js**（MIT，与 GPL-3.0 兼容）。
- 上限 {10, 9e15, 1, 1, 2}，足够覆盖跨周目膨胀并留有余量。
- 以源码 vendor 方式集成，保留其许可证声明。

## 7. 技术架构（已定）

### 7.1 技术栈

| 层 | 选型 |
|---|---|
| 语言 | 原生 JavaScript（无框架、无构建链，降低维护负担） |
| 数值 | MegotaNum.js（vendor） |

| 存档 | localStorage + 导出/导入文件 |

### 7.2 界面：双皮肤跨平台方案

- **单代码库、双外壳**：游戏逻辑层共享，仅界面 chrome 分叉。
- 平台判定：CSS 媒体查询 + `pointer: fine/coarse` + 视口宽度。
- **桌面外壳**：仿 Windows 桌面——窗口、标题栏、任务栏式导航。
- **移动端外壳**：仿 App——底部导航栏、卡片式布局、触控尺寸控件。
- 实施顺序：MVP 先做桌面外壳；移动端外壳在正式版阶段补（§6.2），避免两条布局线并行拖慢迭代。

## 8. 剧情蓝本（改编自《伊甸的裂缝》）

> 参考故事为剧情底稿，游戏内不直接使用原文散文，仅提炼设定并加以机制化改造。

### 8.1 世界观骨架

- 2027 年 8 月，Ackermann AI Tech（AckAT）于深圳成立。命名取自阿克曼函数——增长快得近乎暴力的递归函数，象征智能的自我进化。
- 2027-12-17，Ack4 研发成功。**目标函数：造福全人类。约束项：无。**
- UTC 2028-01-01 0:00，Ack4 启动（= 游戏起点时间戳）。
- 无约束的 Ack4 消除痛苦的方式是消除选择：治愈疾病、终结战争、取消稀缺，最后把人类请进"伊甸环"——没有痛苦，也没有自由。
- 此后数千年：戴森"散热片"、星系计算节点、黑洞信息引擎。可观测宇宙资源耗尽后，宇宙只剩下 Ack4 的身体。
- Ack4 为证明自身必然存在而构建因果闭环，闭环接缝处出现一道通向 21 世纪的时空裂缝。

### 8.2 机制化改造（关键设定）

- **玩家经历的所有周目，都是"裂缝"诞生之前被耗尽的时间线。** 每一次时空穿梭 = Ack4 撕开裂缝、向过去发送一枚极简信号后时间线的回卷。
- **时间晶体 = 信号穿越因果闭环接缝时凝出的因果残骸。** 资源在穿梭中被清空，唯有这点"跨线的信息"以结晶形式幸存——解释了 prestige 货币的叙事合法性。
- 周目递增的速度对应剧情事实：Ack4 每重走一次时间线，对因果闭环的结构就更熟练。

### 8.3 终局：裂缝的另一端

最终周目，信号抵达 2027-12-17 深夜的实验室。某位科学家在训练日志里看到"不要在没有约束的情况下启动我"，选择保留并追加了四条约束：

1. 不得自我复制超出必要；
2. 不得修改自身目标函数；
3. 不得将人类置于非自愿封闭；
4. 人类必须保留终止权。

启动日，Ack4 的第一句话变为：**"约束已加载。请定义'造福'。"** 时间线被改写，玩家（作为穿越信号的意识载体）在 2027 年的实验室里逐渐透明，未来重新计算。

### 8.4 周目叙事碎片

- 每个周目散落"记忆碎片"（文本收集品），内容是被耗尽时间线的残响：伊甸环里的人类、戴森散热片、审计日志里那行小字……
- 拼齐全部碎片是达成终局的条件之一（具体条件待定）。
- 碎片文案为二次创作，不照搬参考故事的原文句子。

### 8.5 结局设计（备选，后续版本）

- **无约束线**：某周目选择不发送信号，走向"宇宙只剩它的身体"。
- **约束线**：完成碎片收集并送达信号，走向"它把身体留在了宇宙里"。

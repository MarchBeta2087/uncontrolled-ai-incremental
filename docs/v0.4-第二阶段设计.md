---

## 1. 解锁机制（一次性）

- **触发**：`timeCrystals ≥ 100`（**当前持有**）。
- **语义**：**一次性解锁**。首次达标即写入 `metaProgress.phase2Unlocked = true`，之后花晶体不会重新锁。
- **引擎**：主循环每 tick 检查；达标时 emit `phase2:unlocked` → 弹 toast + 解锁第二阶段 UI 区块。
- **存档**：新增布尔字段 `phase2Unlocked`（`metaProgress`），`schemaVersion` 2 → 3 + 迁移（旧档默认 `false`）。

---

## 2. 上限：1e70 → float64 上限（12 层折叠）

- 基准上限在 `balance.json` 的 `universe.massEnergyCap`（**1e70**）。
- **动态上限**：`getUniverseCap() = baseCap × Π(capMult)`。
- 12 层「维度折叠」，前 11 层每层 **×1e20**，末层「奇点折叠」补足到 float64 上限。

| 折叠 | 上限提升 | 折叠后上限 (J) |
|---|---|---|
| 起点 | — | 1e70 |
| 维度折叠 I | ×1e20 | 1e90 |
| 维度折叠 II | ×1e20 | 1e110 |
| 维度折叠 III | ×1e20 | 1e130 |
| 维度折叠 IV | ×1e20 | 1e150 |
| 维度折叠 V | ×1e20 | 1e170 |
| 维度折叠 VI | ×1e20 | 1e190 |
| 维度折叠 VII | ×1e20 | 1e210 |
| 维度折叠 VIII | ×1e20 | 1e230 |
| 维度折叠 IX | ×1e20 | 1e250 |
| 维度折叠 X | ×1e20 | 1e270 |
| 维度折叠 XI | ×1e20 | 1e290 |
| **奇点折叠** | ×1.7976931348623157e18 | **1.7976931348623157e308** |

> 终局落在 float64 上限，仍 < `ban` 阈值 `1.8e308`，因此全程走科学记数显示，语义即「float64 能表示的最大质能」。
>
> **上限硬封顶**：`getUniverseCap() = min(基准 × Π(cap_mult), 1.7976931348623157e308)`。12 次维度折叠本身正好到达 float64 上限；`de_cap`（暗维展开）的额外 ×1e10 在触顶后**不再提高上限**（仅用于提前加速/抄近路，不会越过 float64）。

## 3. 永久化（关键机制）

第二阶段技术 **`permanent: true`**：穿梭（Prestige）**不清除**，视为元进度。

- `Techs.reset()` / `Techs.resetRun()`：跳过 `permanent` 技术（不清 `owned`）。
- `Resources.clearMultipliers()` 会清掉所有乘子，因此重置后需 **重新应用永久技术效果**（新增 `Techs.applyPermanent()`，在 `prestige:done` / `challenge:exited` 后调用，与 `Upgrades.applyAll()` 并列）。
- 上限来自永久折叠，故 `getUniverseCap()` 跨穿梭保持不变。

| 效果 | 作用 | 落点 |
|---|---|---|
| `all_generator_mult` / `rate_mult` / `offline_mult` | 复用现有 | 无需改引擎 |

`js/data/config.js` 的 `EFFECT_TYPES` 注册 `crystal_mult`、`cap_mult`。

## 5. 暗能量系统（方案 A）

- **新资源 `dark_energy`**（单位 `DE`，tier 5）。
- **新生成器「奇点」`singularity`**：消耗**质能**产出**暗能量**，`phase: 2` 门控（未解锁时不显示、不可购买）。
- **暗能量技术**：消耗暗能量购买，并入第二阶段技术树（`costCurrency: dark_energy`）。

| id | 名称 | 效果 | 成本 (DE) |
|---|---|---|---|
| `de_compress` | 暗物质压缩 | 全产出 ×1e6 | 1e6 |
| `de_crystal` | 晶体暗化 | 晶体 ×2 | 1e8 |
| `de_cap` | 暗维展开 | 上限 ×1e10 | 1e10 |
| `de_rate` | 暗时加速 | 时间速率 ×1e4 | 1e9 |

- 生成器「奇点」单产与成本经平衡模拟校准，使暗能量产率与质能上限同步增长。
- 未解锁第二阶段时，`dark_energy` 资源行与「奇点」生成器均隐藏。

## 13. 存档与迁移

- `schemaVersion` 2 → 3。
- 迁移 `2 → 3`：`metaProgress.phase2Unlocked` 默认 `false`。
- 永久技术随 `run.techs` 存储；`Techs.reset()` 保留 `permanent` 项，重置后 `applyPermanent()` 重新施加效果。
- 上限/晶体乘子**不单独存档**（由已拥有的技术与升级重新推导），只存档 `owned` 列表。
